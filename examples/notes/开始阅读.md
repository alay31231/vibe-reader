# 让每一次讨论都能回到原文

Vibe Reader 是一个本地阅读器。你可以在这里阅读 Markdown 和纯文本，搜索具体句子，再把带出处的引用复制到讨论中。

## 从一句话开始

阅读时，有些句子会让人停下来。它可能提出一个疑问，也可能改变我们对前一段的理解。给它留下一个链接，下次讨论就能回到同一个位置。

找到你想讨论的段落，选中其中的文字，点击“复制引用”。粘贴到笔记或 AI 对话中，引用会带上文档名和原文行号链接。

## 试试搜索与返回

按 Command/Ctrl + K，搜索“同一个位置”，点击结果回到原文。底部的“返回上一处”会带你回到跳转前的位置。

## 使用自己的材料

点击左上角的 VIBE READER，再点击“把书放进来”；也可以把 Markdown 或纯文本文件拖到页面上。导入文件会保存在本机的 library 目录中。

如果你已有一个材料文件夹，可以在启动时通过 --library 挂载。挂载的原文件保持原样；拖入文件则会保存一份副本。

这份文件是随项目提供的示例，可以自由修改和使用。
